Digite o ISBN de 10 ou 13 dígitos, com ou sem traços. O leitor USB também funciona aqui: é só bipar.

Fila de cadastro

A fila está vazia. Leia o código de um livro, ou teste com um ISBN de exemplo para ver como os dados chegam.

    Os dados vêm da BrasilAPI, que consulta CBL, Mercado Editorial, Google Books e Open Library. Também consulta o Google Books e a Open Library direto. Quando as fontes trazem livros diferentes para o mesmo ISBN, abre uma janela para você escolher o certo. Livro não encontrado continua na fila com o ISBN certo, para completar à mão.

    A fila fica guardada só neste navegador. A planilha sai com uma linha por exemplar e as colunas de tombo, categoria e origem em branco, para completar depois.
